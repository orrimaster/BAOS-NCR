BAOS 판재 절단 계산기 - 모바일 웹 앱 (v1.5.0)
==================================================

이 폴더의 파일을 웹 서버에 그대로 올리면 아이폰과 안드로이드폰에서
앱처럼 설치해서 쓸 수 있습니다.

[폴더 구성]
  index.html              계산기 화면
  manifest.webmanifest    앱 이름, 아이콘 정보
  sw.js                   인터넷 없이도 열리게 하는 오프라인 저장 기능
  icon-192.png            앱 아이콘 (안드로이드)
  icon-512.png            앱 아이콘 (안드로이드, 큰 크기)
  icon-maskable-512.png   앱 아이콘 (안드로이드 둥근 아이콘용)
  apple-touch-icon.png    앱 아이콘 (아이폰)


1. 웹에 올리기
--------------------------------------------------
반드시 https:// 로 시작하는 주소여야 홈 화면 설치와 오프라인 사용이 됩니다.
아래 중 한 곳에 폴더 안의 파일 7개를 모두 올리세요.

  - 회사 웹서버 (IT 부서에 "정적 파일 폴더 하나 https로 공개" 요청)
  - GitHub Pages, Netlify, Cloudflare Pages 같은 무료 정적 호스팅

올린 뒤 휴대폰에서 그 주소를 열어 계산기가 나오면 성공입니다.


2. 휴대폰에 설치하기
--------------------------------------------------
[아이폰]
  1) Safari로 주소를 엽니다. (다른 브라우저는 설치가 안 될 수 있습니다)
  2) 아래쪽 공유 버튼(네모에 위쪽 화살표)을 누릅니다.
  3) "홈 화면에 추가"를 누르고 "추가"를 누릅니다.

[안드로이드]
  1) Chrome으로 주소를 엽니다.
  2) 오른쪽 위 메뉴(점 3개)를 누릅니다.
  3) "앱 설치" 또는 "홈 화면에 추가"를 누릅니다.

설치 후에는 홈 화면의 BAOS 아이콘으로 실행합니다.
한 번 실행한 뒤에는 인터넷이 없어도 열립니다.


3. 수정해서 다시 올릴 때
--------------------------------------------------
  - index.html 등을 바꿔서 다시 올리면 됩니다.
  - sw.js 맨 위의 CACHE 값(예: "baos-cut-v1.5.0")도 새 버전으로 바꿔 주세요.
    그래야 이미 설치한 휴대폰에도 새 화면이 반영됩니다.
  - 휴대폰에서는 앱을 한 번 껐다 켜면 새 버전으로 바뀝니다.
